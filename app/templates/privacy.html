Privacy Policy

This application, LinkedIn Auto-Post, is a personal automation tool used only by its owner.

What data is processed

The app stores the owner's LinkedIn profile summary, API keys, access tokens and generated post drafts in a local SQLite file (data/app.db) on the owner's computer. No data is sent to any server other than the services the owner explicitly connects: the chosen AI provider (Anthropic or OpenAI) and the LinkedIn API.

How data is used

Profile information is used only to generate draft posts. LinkedIn data is used only to publish posts that the owner has reviewed and approved inside the local dashboard. Content is never sold, shared or used for advertising.

Data retention

All data remains on the owner's computer until the owner deletes the local database or individual drafts. Nothing is stored in a cloud database by this app.

Third-party services

When connected, this app calls the LinkedIn API to publish approved posts and an AI provider API to draft text. Those services process requests under their own privacy policies.

Contact

For any question about this tool, contact the owner of the LinkedIn account that authorized it.
